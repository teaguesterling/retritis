An agent's interactive field guide

Retritis

A suite of MCP tools that turns a codebase into queryable data and gives a coding agent typed, indexed, policy-aware tools — instead of grep | sed | cat.

The one move: the codebase is already a database — query it, don't re-derive it with a shell. Every time you reach for bash to inspect, search, read, run, or commit — ask if a tool already knows the answer as data. Almost always, yes.

④ Two mental models

The patterns that keep the abstract tools composable.

Generators vs. runtimes

A generator produces an artifact offline; a runtime consumes it online. Different trust models — don't fuse them.

generator → artifact
agent-riggs → umwelt rules
lackpy-gen → program
runtime consumes
umwelt resolves rules
lackpy runs the program

Shape-driven vs. context-driven

The split that keeps applicability separate from policy.

shape
“can this fit into that?”
type / structure / applicability. (e.g. an addressing layer like goo.)
context
“what constraints are on that when it's over here?”
mode / event / session, with override. (umwelt.)
